# Nelson's Files – e-Portfolio

Individual assignment for **CIS222 Web Design and Development / CIS282 Web Development and Security** (Saint Francis University).

A personal e-portfolio website designed like an archive: every page is a coloured folder with paper sheets, index cards, sticky notes and stamps, made with HTML, CSS and JavaScript only.

## Pages
| File | Page |
|---|---|
| `index.html` | Home – folder stack |
| `personal.html` | About Me – key facts, career objective, Word profile, audio introduction |
| `experience.html` | Working experience (accordion) and course projects |
| `education.html` | Education background |
| `skills.html` | Skills (tabs, animated bars) and Tutorial 7 JavaScript tools |
| `projects.html` | Live demos of my tutorial work |
| `other.html` | Hobbies, fun facts and contact form |
| `sitemap.html` | Site map |
| `thankyou.html` | Shows the contact form data (sessionStorage) |

Open `index.html` in a browser to view the site.
